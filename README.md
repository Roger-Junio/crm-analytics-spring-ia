# CRM Inteligente

> Produto interno em desenvolvimento para análise de dados próprios de uma empresa e geração de insights utilizando Backend, Banco de Dados e Inteligência Artificial.

## 📌 Sobre o projeto

O **CRM Inteligente** é um projeto desenvolvido como parte do meu processo de **desenvolvimento profissional e aprofundamento em engenharia de software**.

A ideia é construir uma aplicação que possa ser utilizada dentro de uma empresa para receber e analisar **seus próprios dados**, inicialmente através de arquivos CSV.

A partir desses dados, o sistema realiza o processamento, armazenamento e aplicação de regras de negócio, criando uma base para análises e, posteriormente, consultas utilizando Inteligência Artificial.

> 🚧 **Projeto em desenvolvimento:** a aplicação está sendo construída de forma incremental, desde a modelagem e estrutura do backend até as funcionalidades de análise e IA.

---

## 🎯 Objetivo

Transformar dados já existentes dentro de uma empresa em informações úteis para análise e tomada de decisão.

A proposta é permitir que o usuário importe seus próprios dados e consiga realizar análises sem precisar trabalhar manualmente com grandes arquivos.

Exemplos de perguntas que o sistema poderá responder:

```text
Quais clientes estão há mais de 60 dias sem comprar?

Quais clientes possuem maior valor total de compras?

Quais clientes apresentam sinais de perda de recorrência?
```

## 🔄 Fluxo do produto

```text
Dados próprios da empresa
          ↓
        CSV
          ↓
       Upload
          ↓
       Backend
          ↓
     Banco de Dados
          ↓
 Processamento e regras
          ↓
       Análises
          ↓
 Contexto relevante
          ↓
 Inteligência Artificial
          ↓
        Insights
```

A proposta é que o **Backend processe e filtre os dados antes da utilização da IA**, evitando enviar informações desnecessárias e mantendo maior controle sobre o fluxo de dados.

## 🤖 Inteligência Artificial

A Inteligência Artificial faz parte da evolução planejada do produto.

A proposta não é transformar o sistema em apenas um chatbot.

O Backend deverá identificar os dados necessários, consultar o banco, organizar as informações e fornecer à IA somente o contexto relevante para interpretação.

```text
Pergunta
   ↓
Backend
   ↓
Consulta ao banco
   ↓
Filtragem dos dados
   ↓
Contexto
   ↓
IA
   ↓
Resposta / Insight
```
